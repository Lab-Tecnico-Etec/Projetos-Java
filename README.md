## Estrutura

- `listaA/`
- `listaAExtra2/`
- `listaD/`
- `listaExtra/`
- `listaF/`

Os nomes refletem a organização de origem. Cada exercício pode ser independente e exigir compilação separada.

## Como executar

1. Instale um JDK compatível.
2. Abra o arquivo desejado em uma IDE Java ou terminal.
3. Confira se a classe pública corresponde ao nome do arquivo.
4. Compile e execute individualmente conforme a estrutura.

Exemplo para uma classe sem declaração de pacote:

```bash
javac listaA/A1.java
java -cp listaA A1
```

Ajuste o comando conforme a classe e a estrutura de cada exercício.
